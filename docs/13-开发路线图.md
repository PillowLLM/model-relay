# 13 开发路线图（M1–M5）

> 每阶段结束有明确验收标准。**多人并行**：后端按模块认领（README 认领规则），前端按页面认领（11/14 文档接口契约），接口联调在 M3 集中进行。负责人列由项目负责人在开工时填入认领人。

## M1 MVP —— 可对话

**目标**：`/v1/chat/completions` 非流式可用，单渠道，令牌鉴权。

| 任务 | 模块文档 | 依赖 |
|------|---------|------|
| workspace 骨架 + Cargo.toml + 目录 | 00 | — |
| relay-core：AppError/Config/util/crypto | 03 | — |
| relay-store：建表 + Store trait + SqliteStore | 01 | 03 |
| relay-provider：OpenAiCompat + DeepSeek 渠道 | 04 | 03 |
| relay-autofit：detect_inbound + parse_openai + to_openai | 05 | 03 |
| relay-gateway：基础管线（鉴权→选渠道→转发→结算） | 07 | 04/05/08 |
| relay-billing：pricing + record_usage | 08 | 01 |
| relay-api：/v1/* + 管理 API 骨架 | 14 | 07 |
| relay-server：启动 + 初始 admin | 12 | 全部 |
| relay-health：启动自检 | 10 | 01 |

**验收**：
- [ ] 启动自检绿灯，`RELAY_ADMIN_PASSWORD` 缺失拒绝启动
- [ ] `curl /v1/chat/completions`（DeepSeek 渠道）返回正常 JSON
- [ ] 无令牌 401；错误令牌 401
- [ ] 用量日志落库
