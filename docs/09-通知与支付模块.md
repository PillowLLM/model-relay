# 09 通知与支付模块（relay-notify）

## 1. 职责

- 外部接入：短信（阿里云/腾讯云）、邮箱（SMTP）、支付（支付宝/微信/手动码）
- 业务事件 → 模板消息 → 发送（解耦，见 15 文档事件清单）
- 充值订单与支付回调

## 5. 通知模板

| 模板 | 场景 | 短信文案示例 |
|------|------|-------------|
| `quota_low` | 额度 ≤20% | 「您的模型额度已使用 80%，剩余 xxxx token」 |
| `quota_exhausted` | 额度耗尽 | 「额度已用完，请充值或联系管理员」 |
| `payment_success` | 充值到账 | 「充值 ¥xx 成功，到账 xxxx token」 |
| `channel_down` | 渠道自动禁用 | 「渠道「DeepSeek」连续失败已自动禁用」 |
| `daily_report`（可选） | 每日用量 | 「昨日用量：xxx 请求 / xxx token / ¥xx」 |

模板文案集中在 `notify::templates` 模块，ctx 键：`{user_name, remaining, amount, quota, channel_name}`。

## 6. 支付接入

### 6.1 支付宝当面付（自动确认）

```
config_enc: {"app_id":"...","private_key":"...","alipay_public_key":"...","notify_url":"https://relay.yxpil.com/api/pay/notify/alipay"}
下单：POST /v3/gateway.do?method=alipay.trade.precreate（二维码 qr_code）
回调：POST /api/pay/notify/alipay
  1. 验签（alipay 公钥 + RSA2）
  2. 查订单号 → 状态 pending → paid → billing.add_quota
  3. 返回 "success" 给支付宝（防重试）
```

### 6.2 微信 Native（自动确认）

```
config_enc: {"appid","mch_id","api_key_v3","serial_no","private_key","notify_url"}
下单：POST /v3/pay/transactions/native（返回 code_url → 二维码）
回调：POST /api/pay/notify/wechat（AES-GCM 解密 + 验签）
```

### 6.3 手动收款码

```
config_enc: {"image_url":"/uploads/qr_wechat.png","note":"备注暗号"}
流程：用户下单(manual) → 返回收款码图 + 暗号 → 用户付款后备注暗号 → 管理员 PUT confirm 到账
```

## 7. 充值订单流程（完整）

```
POST /api/recharge/order {plan_id, pay_method}
  → 校验档位/方法
  → INSERT recharge_orders(pending)
  → 返回 {order_no, amount, quota, qr_url}
      ↓（官方支付：用户扫码支付）
支付宝/微信回调 → 验签 → 状态 pending→paid → billing.add_quota → notification_logs(payment_success)
      ↓（手动）
管理员确认 → PUT /api/admin/recharge-orders/{id}/confirm → 同上
```
