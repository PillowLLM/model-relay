# 07 请求管线模块（relay-gateway）

## 1. 职责

编排一次转发的完整生命周期：鉴权 → 限流 → 配额 → 渠道选择 → 转换 → 转发 → 重试/故障转移 → 结算 → 日志。

## 3. 管线流程（伪代码）

```rust
pub async fn handle_chat(&self, path, headers, raw) -> Result<Response, AppError> {
    // 1. 入站识别
    let fmt = autofit.detect_inbound(path, headers, &raw);
    if fmt == Unknown { return Err(AppError::bad_request("无法识别的请求格式")); }
    let req = autofit.parse(fmt, &raw)?;

    // 2. 令牌鉴权
    let (token, user, group) = self.authenticate(headers)?;   // 401/403 见 02 文档

    // 3. 限流
    self.limits.check_token_concurrency(token.id)?;           // 429
    self.limits.check_user_rpm(user.id)?;                     // 429

    // 4. 配额预检（用量估计）
    let est = self.billing.estimate_cost(&req, &group)?;
    self.billing.check_quota(&token, &user, est.upper_cost)?; // 429 "额度不足"

    // 5. 渠道选择（含模型映射）
    let channels = self.select_channels(&req.model, user.group_id)?;
    if channels.is_empty() { return Err(AppError::bad_request("没有可用渠道或模型不支持")); }

    // 6. 转发 + 重试 + 故障转移
    let mut last_err = None;
    for (attempt, chan) in channels.iter().take(1 + chan.max_retries).enumerate() {
        if self.failures.is_cooldown(chan.id) { continue; }
        let mapped = self.apply_model_mapping(&req, chan)?;
        let out_req = autofit.to_provider(&mapped, &chan.r#type)?;
        let t0 = Instant::now();
        match self.providers.get(&chan.r#type)?.chat(&mapped, chan).await {
            Ok(resp) => {
                self.failures.reset(chan.id);
                let latency = t0.elapsed().as_millis() as i64;
                // 7. 结算
                let usage = resp.usage.clone().unwrap_or_else(|| self.tokenizer.fallback_count(&mapped, &resp));
                self.billing.record_usage(&token, &user, &group, chan, &req.model, &usage, latency, "success", None).await?;
                // 8. 响应转换（按入站格式）
                return Ok(autofit.to_client(&resp, fmt));
            }
            Err(e) => {
                self.failures.note_failure(chan.id);          // 自动禁用逻辑（10 文档）
                last_err = Some(e);
                if !self.is_retryable(&e) { break; }          // 400/401 类不重试
                tokio::time::sleep(Duration::from_millis(200 * (attempt as u64 + 1))).await;  // 退避
            }
        }
    }
    Err(last_err.unwrap_or(AppError::internal("所有渠道均失败")))
}
```

## 6. 重试与故障转移规则

| 条件 | 动作 |
|------|------|
| 上游 400/401/403/404 | 不重试，透传 |
| 上游 429 | 重试 ≤ max_retries（退避 200ms×n） |
| 上游 5xx / 超时 / 连接失败 | 换下一渠道重试 ≤ max_retries |
| 全部失败 | 502，错误写入 usage_logs(status=error) |
| 渠道 cooldown（60s） | 选择时跳过 |
| 连续失败 ≥5 且 auto_ban | 自动禁用 + notify(channel_down)（10 文档） |

## 8. 并发保护

- 每令牌并发 ≤10（`tok:{id}` 计数，进入+1 离开-1，超限 429）
- 每渠道并发 ≤20（拼车池保护，超限暂不选该渠道）
- 全局信号量上限 200（防上游雪崩，tokio::sync::Semaphore）
