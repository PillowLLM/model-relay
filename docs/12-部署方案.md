# 12 部署方案（doc.yxpil.com）

> 目标：与 DocPI 同服务器部署，`relay.yxpil.com` 子域名（方案 A，推荐）或 `doc.yxpil.com/relay/` 子路径（方案 B）。

## 1. 二选一方案

### 方案 A：子域名 relay.yxpil.com（推荐）

```
DNS: relay.yxpil.com A 记录 → 服务器 IP
nginx: server_name relay.yxpil.com; 反代 127.0.0.1:8322
```

### 方案 B：子路径 doc.yxpil.com/relay/

```
nginx: location /relay/ { proxy_pass http://127.0.0.1:8322/; }
客户端 base_url: https://doc.yxpil.com/relay/v1
注意：relay-server 的 public 前端需处理相对路径（base href），或用独立子域规避
```

## 2. 构建（Windows 交叉编译，zig 工具链已就绪）

```powershell
# 环境变量（沿用 DocPI 方案）
$env:CC_x86_64_unknown_linux_musl = "C:\zig\zig-cc.bat"
$env:CARGO_TARGET_X86_64_UNKNOWN_LINUX_MUSL_LINKER = "C:\zig\zig-cc.bat"

# 构建静态二进制（zig cc + self-contained=no 防 crt1 冲突）
cargo build --release --target x86_64-unknown-linux-musl --workspace
cargo rustc --release --target x86_64-unknown-linux-musl --bin relay-server -- -C link-self-contained=no

# 前端
cd frontend && npm run build
```

产物：`crates/relay-server/target/x86_64-unknown-linux-musl/release/relay-server` + `public/`

## 3. 服务器结构

```
/opt/relay/
├── relay-server        # 3-5MB 静态二进制
├── public/             # 前端产物（必须同目录，ServeDir 读磁盘）
├── data/               # SQLite 库 + uploads（运行时生成）
└── .env                # 环境变量（chmod 600）
```

## 4. 环境变量

```bash
# /opt/relay/.env（systemd EnvironmentFile）
RELAY_PORT=8322
RELAY_DATA_DIR=/opt/relay/data
RELAY_PUBLIC_DIR=/opt/relay/public
RELAY_ADMIN_USERNAME=admin
RELAY_ADMIN_PASSWORD=<强密码>
RELAY_MASTER_KEY=<32字节hex，首次生成后保存>
# 可选
RELAY_DISABLE_CAPTCHA=1   # 仅测试
```

## 5. systemd 服务

```ini
# /etc/systemd/system/relay.service
[Unit]
Description=Model Relay
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/relay
EnvironmentFile=/opt/relay/.env
ExecStart=/opt/relay/relay-server
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload && systemctl enable --now relay
systemctl status relay          # 日志出现 "Relay 已启动: http://0.0.0.0:8322" 即成功
```

## 6. nginx 配置（方案 A）

```nginx
server {
    listen 443 ssl;
    server_name relay.yxpil.com;
    ssl_certificate     /etc/nginx/ssl/yxpil.com.pem;
    ssl_certificate_key /etc/nginx/ssl/yxpil.com.key;

    client_max_body_size 16m;            # 图片 base64 请求

    location / {
        proxy_pass http://127.0.0.1:8322;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE 关键三件套
        proxy_buffering off;
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }
}
```

## 7. 防火墙

```bash
ufw allow 8322/tcp   # 仅限 127.0.0.1 时可不放行（nginx 反代即可）
```

## 8. 升级流程

```bash
# 1. 传新二进制 + public/
# 2. 备份：sqlite3 /opt/relay/data/relay.db ".backup /opt/relay/backup-$(date +%F).db"
# 3. systemctl restart relay
# 4. curl http://127.0.0.1:8322/api/auth/captcha   # 200 即通
# 5. 前端 Ctrl+F5（版本号自动换缓存）
```

## 9. 安全清单

- [ ] 8322 只监听 127.0.0.1（或防火墙仅限本机）
- [ ] RELAY_ADMIN_PASSWORD 强密码 + .env 600 权限
- [ ] RELAY_MASTER_KEY 备份保存（丢失则渠道 Key 无法解密）
- [ ] HTTPS 强制（nginx 80 → 443 跳转）
- [ ] 渠道 Key 加密存储，日志无密钥
