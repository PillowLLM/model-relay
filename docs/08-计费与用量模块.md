# 08 计费与用量模块（relay-billing）

## 1. 职责

- 模型定价管理
- 用户/令牌双层配额 + 组倍率
- 前置用量估计、后置结算、兜底计数
- 兑换码、充值到账
- 用量统计（按模型/渠道/天/用户）

## 3. 定价与费用计算

```rust
// 单价：pricing 表（元/1M token）；缺省 0（免费模型）
pub fn calc_cost(prompt: u32, completion: u32, p: &Pricing, multiplier: f64) -> f64 {
    (prompt as f64 / 1_000_000.0 * p.prompt_price
     + completion as f64 / 1_000_000.0 * p.completion_price) * multiplier
}
```

**组倍率**：`multiplier = group.quota_multiplier`（默认 1.0；VIP 组可 0.8 打折，运营组可 1.5）。

## 4. 配额模型（拼车核心）

```
用户配额：users.quota_limit（-1 不限）/ used_quota
令牌配额：tokens.quota_limit（-1 不限）/ used_quota
检查顺序：令牌先查 → 用户后查（任一超限 → 429）
扣减：used_quota += prompt+completion（令牌和用户都扣）
```

```rust
pub async fn check_quota(&self, token: &Token, user: &User, upper_cost: f64) -> Result<(), AppError> {
    // 用量估计的 upper_cost 已包含组倍率
    if token.quota_limit >= 0 && token.used_quota >= token.quota_limit {
        return Err(AppError::RateLimited("令牌额度已用完".into()));
    }
    if user.quota_limit >= 0 && user.used_quota >= user.quota_limit {
        return Err(AppError::RateLimited("账号额度已用完".into()));
    }
    Ok(())
}
```

**额度事件**（→ notify）：
- `used_quota >= limit * 0.8` 首次触发 → `quota_low`
- 耗尽（429）→ `quota_exhausted`
- 事件去重：每令牌每事件 24h 最多一次（settings 记录 last 时间戳）

## 5. 结算

    let cost = calc_cost(usage.prompt_tokens, usage.completion_tokens, &p, group.quota_multiplier);

    //   3. UPDATE users SET used_quota += total

## 6. 兑换码

```rust
pub async fn redeem_code(&self, code: &str, user_id: i64) -> Result<i64> {
    let c = self.store.get_redeem_code(code).await?
        .ok_or_else(|| AppError::bad_request("兑换码不存在"))?;
    if c.status != 0 { return Err(AppError::bad_request("兑换码已使用或禁用")); }
    if let Some(exp) = &c.expires_at { if exp < now_str() { return Err(AppError::bad_request("兑换码已过期")); } }
    // 事务：
    //   1. UPDATE redeem_codes SET status=1, used_by, used_at WHERE id=? AND status=0
    //   2. 受影响行数=0 → 并发冲突 → 400 "已被使用"
    //   3. UPDATE users SET used_quota -= quota（加额度）
    Ok(c.quota)
}
```

## 7. 充值（与 relay-notify 联合）

```
POST /api/recharge/order {plan_id, pay_method}
  → 取 settings.recharge_plans 档位（金额/到账额度）
  → 生成 recharge_orders(pending) + order_no
  → 支付方式：
     - alipay/wechat 官方：调用 notify.pay_create() 拿二维码/链接 → qr_url
     - manual：返回管理员收款码图片 URL（notify 配置 qr_manual）
回调：/api/pay/notify/{method}（验签，见 09 文档）
  → 订单 paid → billing.add_quota(user) → notify.send(payment_success)
手动确认：PUT /api/admin/recharge-orders/{id}/confirm → 同上
```
