# 10 自检与监控模块（relay-health）

## 1. 职责

- 启动完整性检验（fail-fast）
- 运行期：数据库完整性、渠道健康探测、失败统计
- 管理端状态面板数据源 + 渠道异常告警

## 2. 核心结构

```rust
// crates/relay-health/src/lib.rs
pub struct HealthService {
    store: Arc<dyn Store>,
    providers: Arc<ProviderRegistry>,
    notify: Option<Arc<NotifyService>>,
    cfg: Config,
    failures: Arc<FailureTracker>,          // 与 gateway 共享
    last_report: RwLock<HealthReport>,
}

#[derive(Clone, Serialize)]
pub struct CheckResult { pub name: String, pub status: String,   // ok / warn / fail
    pub detail: String, pub latency_ms: u64 }

#[derive(Clone, Serialize)]
pub struct ChannelHealth { pub channel_id: i64, pub name: String, pub healthy: bool,
    pub latency_ms: u64, pub consecutive_failures: u32, pub last_error: String }

#[derive(Clone, Serialize)]
pub struct HealthReport { pub ok: bool, pub started_at: String, pub checks: Vec<CheckResult>,
    pub channels: Vec<ChannelHealth> }

// 失败跟踪器（gateway 写入，health 读取/清零）
pub struct FailureTracker { map: Mutex<HashMap<i64, (u32, Instant)>> }
impl FailureTracker {
    pub fn note_failure(&self, channel_id: i64);       // gateway 调用
    pub fn reset(&self, channel_id: i64);
    pub fn consecutive(&self, channel_id: i64) -> u32;
    pub fn is_cooldown(&self, channel_id: i64) -> bool; // 最近 60s 内失败过
}
```

## 4. 周期任务（tokio::spawn）

```rust
pub fn spawn_health_loop(svc: Arc<HealthService>) {
    tokio::spawn(async move {
        let mut tick = tokio::time::interval(Duration::from_secs(svc.cfg.health_interval_secs));
        loop {
            tick.tick().await;
            let report = svc.run_probe().await;
            *svc.last_report.write().unwrap() = report;
        }
    });
}

async fn run_probe(&self) -> HealthReport {
    // 1. PRAGMA integrity_check（每日：用 last_check 记录判断）
    // 2. 并发探测所有启用渠道（JoinSet，每渠道 3s 超时）：
    //    provider.list_models(chan) → healthy + latency
    //    失败 → failures.note_failure → >=5 且 auto_ban → store.update_channel_status(0) + notify(channel_down)
    // 3. 汇总 HealthReport
}
```

## 6. 与其它模块联合

| 模块 | 关系 |
|------|------|
| relay-gateway | 共享 FailureTracker（gateway 写失败，health 读统计/禁用）；cooldown 由 selector 查询 |
| relay-provider | 探测调用 provider.list_models |
| relay-notify | 渠道自动禁用 → notify(channel_down) |
| relay-server | 启动自检 fail-fast；spawn 周期任务 |
