# 03 核心类型与配置（relay-core）

> relay-core 不依赖任何业务 crate。全部公共类型在此定义，其他 crate 引用。

## 1. 统一错误 AppError

```rust
// crates/relay-core/src/error.rs
#[derive(Debug, Clone)]
pub enum AppError {
    BadRequest(String),                  // 400
    Unauthorized(String),                // 401
    Forbidden(String),                   // 403
    NotFound(String),                    // 404
    RateLimited(String),                 // 429（限流/额度不足）
    ProviderError { status: u16, message: String },   // 上游错误（透传状态码）
    Internal(String),                    // 500
}

impl AppError {
    pub fn bad_request(msg: impl Into<String>) -> Self;
    pub fn unauthorized(msg: impl Into<String>) -> Self;
    // ...
    pub fn status(&self) -> u16;
    pub fn message(&self) -> &str;
}

// 转换 trait（在 relay-api 实现，不在 core——保持 core 无 HTTP 依赖）
// impl IntoResponse for AppError（JSON：{"error": message, "code": status}）

// 便捷宏（可选）
#[macro_export]
macro_rules! bail_err { ($e:expr) => { return Err($e.into()); } }
```

**约定**：业务层只构造 AppError；ProviderError 携带上游 status 用于透传（如上游 429 → 客户端 429）。

## 2. 请求/响应类型

### 2.1 CanonicalRequest（AUTOFIT 统一中间格式）

```rust
// crates/relay-core/src/request.rs
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct CanonicalRequest {
    pub model: String,
    pub messages: Vec<CanonicalMessage>,
    pub system: Option<String>,          // A社顶层 system 归一到这里
    pub max_tokens: Option<u32>,         // A社必填 → 缺省给默认（4096）
    pub temperature: Option<f32>,
    pub top_p: Option<f32>,
    pub stream: bool,
    pub tools: Option<Vec<CanonicalTool>>,
    pub tool_choice: Option<Value>,
    pub stop: Option<Vec<String>>,
    pub user: Option<String>,            // 透传
    pub extra: HashMap<String, Value>,   // 未知字段透传，不丢信息
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct CanonicalMessage {
    pub role: String,                    // system / user / assistant / tool
    pub content: Vec<ContentPart>,
    pub name: Option<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum ContentPart {
    Text { text: String },
    Image { url: String, detail: Option<String> },
    ToolUse { id: String, name: String, input: Value },
    ToolResult { id: String, content: String, is_error: bool },
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct CanonicalTool {
    pub name: String,
    pub description: Option<String>,
    pub parameters: Value,               // JSON Schema
}

// 响应
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct CanonicalResponse {
    pub id: String,
    pub model: String,
    pub content: String,                 // 主文本（拼接各块）
    pub finish_reason: Option<String>,
    pub usage: Option<TokenUsage>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TokenUsage {
    pub prompt_tokens: u32,
    pub completion_tokens: u32,
    pub total_tokens: u32,
}

// 流式块（AUTOFIT 转换后的统一事件）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum StreamEvent {
    TextDelta { text: String },          // 增量文本
    ToolUseDelta { index: usize, name: Option<String>, input_delta: String },
    ToolResultDelta { index: usize, content: String },
    Usage { usage: TokenUsage },
    Done,
}
```

## 3. 配置 Config

```rust
// crates/relay-core/src/config.rs
#[derive(Clone, Debug)]
pub struct Config {
    pub port: u16,                       // RELAY_PORT 默认 8322
    pub data_dir: String,                // RELAY_DATA_DIR 默认 ./data
    pub public_dir: String,              // RELAY_PUBLIC_DIR 默认 ./public
    pub admin_username: String,          // RELAY_ADMIN_USERNAME 默认 admin
    pub admin_password: String,          // RELAY_ADMIN_PASSWORD 必设
    pub master_key: [u8; 32],            // RELAY_MASTER_KEY（32 字节 hex）；缺失则首启生成并打印一次
    pub disable_captcha: bool,           // RELAY_DISABLE_CAPTCHA=1（测试用）
    pub default_max_tokens: u32,         // 4096
    pub default_timeout_ms: u64,         // 60000
    pub max_retries: u32,                // 默认 1（可被渠道配置覆盖）
    pub health_interval_secs: u64,       // 渠道探测周期，默认 300
    pub rate_limit_per_min: u32,         // 用户级 RPM，默认 60
    pub tokenizer_family_default: String,// cl100k_base
}

impl Config {
    pub fn from_env() -> Self;           // 读取环境变量，缺失用默认
    pub fn validate(&self) -> Result<(), String>;  // 自检用：admin_password 非空、master_key 存在等
}
```
